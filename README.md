## ⚡ Как я работаю

Я собираю проекты на **вайб-кодинге**: ИИ-инструменты берут на себя рутину и ускоряют разработку, а я отвечаю за архитектуру, качество и результат, который можно передать клиенту.

1. **Разбираю задачу** — что нужно бизнесу, а не только «сделать сайт».
2. **Показываю прототип или каркас** — в зависимости от задачи, до основной разработки.
3. **Разрабатываю итерациями** — с промежуточными демо и правками по ходу.
4. **Запускаю** — проверяю сценарии и передаю проект.
5. **Остаюсь на связи** — 14 дней бесплатно исправляю ошибки, дальше доработки по договорённости.

## 📌 Избранный проект

### СТО «Армада Моторс» — мобильное приложение

Приложение для сети автосервисов в Санкт-Петербурге: клиент выбирает услугу, записывается на удобное время и следит за статусом заявки.

**Стек:** Flutter · Dart · 1С-Битрикс · PHP · REST API

- каталог услуг;
- запись на сервис без регистрации;
- статусы записей: новая → подтверждена → в работе → выполнена;
- REST-методы на стороне 1С-Битрикс для работы приложения.
